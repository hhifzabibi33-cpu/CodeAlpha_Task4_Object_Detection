# CodeAlpha_Task4_Object_Detection
Real-time Object Detection and Tracking using YOLO, OpenCV and ONNX Runtime.

This project implements real-time object detection and tracking using a pretrained YOLO model, OpenCV, and ONNX Runtime.

The system captures video through a webcam, detects objects in real time, draws bounding boxes around detected objects, and displays object labels, confidence scores, and tracking IDs.

## Features

- Real-time webcam input
- YOLO-based object detection
- Bounding boxes
- Object labels
- Confidence scores
- Object tracking
- Tracking IDs
- Real-time visualization

## Technologies Used

- Python
- YOLO
- OpenCV
- NumPy
- ONNX Runtime
